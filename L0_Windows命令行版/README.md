# 电商主图批量套版工具 L0（Windows 双击版）

## 设计师只需要做一件事

双击 `L0_Start.cmd`。

这个入口会打开任务设置窗口。任务结束后只显示结果提示，不会自动打开任何文件夹；需要查看成品时点击【立即查看】即可。

完整便携包已经内置工具包私有 Python/openpyxl/et-xmlfile，首次运行不需要联网。只有当 `_internal\runtime\python\python.exe` 缺失、损坏或版本不匹配时，入口才会联网从官方源自动修复；如果无网或权限/网络受限，诊断报告会明确说明失败原因。

## 运行时会让你选择什么

双击后会出现一个任务设置窗口。生成前可以在同一个窗口里反复确认和修改：

1. 商品信息表格：可选择或直接更换。
2. 主图模板：可选择或直接更换。
3. 成品保存位置：可选择或直接输入已授权的本地或 SMB/UNC 路径。
4. 数据工作表：会随当前表格自动读取；更换表格后点击【读取工作表】即可更新下拉选项。
5. 要生成的商品：默认【全部商品】，也可以选择部分商品并用 Ctrl 或 Shift 选择一个或多个商品。
6. 确认无误后点击【检查并开始生成】。

点击【检查并开始生成】后，工具会先确认主图模板能否直接套图。若需要处理，会提示是否生成一个 `原文件名_套版模板.psd` 副本；原始 PSD 不会被修改。

PSD 通过检查后，工具会完成 Excel 字段和图片路径校验。若发现不合格记录，会立即列出商品文件名和具体原因，并提供两种选择：继续只处理合格商品，或取消本次任务后修改表格。不会等整批导出结束才告知表格问题。

价格由 `价格1` 和 `价格2` 两个 PSD 文本层共同展示。两项都必须填写；`价格2` 是展示文案，不校验其必须为小数、折、元或卷，填写什么就按原样展示在 `价格1` 后。

PSD 中存在、但当前 Sheet 未提供对应列的可选 `#开关` 组会默认隐藏，不算字段错误；只有 Sheet 实际提供该开关列却没有填写“是/否”时，才会提示校验问题。

可选素材不需要写死字段名。设计师在 PSD 中用 `#小尺寸` 包住 `!小尺寸图`，并在 Excel 第一列增加 `小尺寸图` 即可。工具会读取所有合规的可选 Excel 行，仅替换 PSD 中同名的 `!` 或 `@` 图层。可选 `#组` 只有在组内所有 `!图片` 都有可访问的路径时才显示；PSD 没有该组、Excel 未填写或路径不存在时，整组隐藏，不报错、不阻断主图导出。

完成提示会显示本次任务耗时。点击【确定】关闭提示；点击【立即查看】才会打开本次任务的 `成品图` 目录。

工具会把上次确认的 Excel、PSD、输出保存位置、Sheet 和商品范围保存到本包 `_settings.json`，方便下次自动带出。旧路径如果不存在或不可访问，只会显示提示并要求重新选择，不会自动开始生成。业务变量、图片路径和映射规则仍只来自 Excel 和 PSD。

运行中的常驻窗口会显示当前阶段；Photoshop 开始导出后，Photoshop 内还会显示当前商品进度。

## 素材读取规则

不再选择素材文件夹，也不会扫描共享盘。Excel 的 `堆图`、`大尺寸` 等图片字段必须填写文件的完整 UNC 或 Windows 本地绝对路径，例如 `\\10.1.212.3\家清设计中心\...\TKDT3180-3.png`。

`商品图` 是必填项。商品图未填写、只填写文件名、路径不可访问或文件不存在时，该商品会在 Photoshop 启动前写入 `异常记录.csv`，不会生成 `data.csv` 任务、更不会导出错误成品。可选图片字段填写 `无.png` 或 `无` 时按关闭处理。

## 失败时看哪里

如果没有正常出图，直接把本包下面的 `_diagnostics` 文件夹发给开发同事。里面会有固定诊断文件，例如：

- `start.log`
- `status.json`
- `status.txt`
- `failure.txt`
- `failure.csv`
- `ps1_started.marker`

不需要截图，不需要自己输入命令。

## 使用前提

1. Windows 10 x64 或以上。
2. 已安装 Windows 版 Photoshop，并且 M1 验证通过。Photoshop 是授权软件，本工具只做 COM 预检和调用，不自动安装 Photoshop。
3. 本包只使用工具包私有运行时 `_internal\runtime\python\python.exe`；完整便携包首次运行不联网。若运行时缺失、损坏或版本不符合固定要求，会自动从官方源下载并重新配置，不要求你手工安装 Python/openpyxl/et-xmlfile，也不会使用 WindowsApps 或系统 Python。
4. 如果 Excel 里的图片路径是 SMB/UNC 路径，用户需要先在 Windows 中具备访问权限；工具不自动挂载网络盘、不保存账号密码。
5. PSD 图层按规范命名：
   - `@字段名`：文本变量层
   - `!商品图`：智能对象图片替换层
   - `#开关名`：是/否控制显隐的组或层

可选素材组上线前由模板设计师验收：若 Excel 同时提供可选图片路径，工具会展示 PSD 中对应的 `#组` 和 `!图片`。因此设计师必须确认该组确有展示位置、层级正确，且不会压住价格、文案或其他固定元素。

## 输出内容

每次运行会在你选择的输出位置生成一个 `套版任务_yyyyMMdd_HHmmss_fff` 文件夹：

- `data.csv`：清洗后的套版数据。
- `异常记录.csv`：数据接入层发现的问题。
- `L0任务报告.txt`：启动器、清洗、Photoshop 执行过程日志。
- `成品图/`：导出的 JPG 主图。
- `成品PSD/`：同名的可编辑 PSD 成品。
- `成品图/结果报告.csv`：逐商品处理状态、JPG 路径和 PSD 路径。

## 当前 L0 边界

- 不自动挂载 SMB、不保存凭据；Excel 中的 SMB/UNC 图片路径需在 Windows 中已经可以访问。
- 不选择、不写入、不递归扫描素材共享盘；只读取 Excel 当前商品单元格所指向的文件。
- 完整便携包已内置工具包私有 Python `3.11.9`、openpyxl `3.1.5`、et-xmlfile `2.0.0`；所有业务执行始终只调用 `_internal\runtime\python\python.exe`，不会 fallback 到 WindowsApps 或系统 Python。只有运行时缺失、损坏或版本不匹配时才联网修复。Python 运行时仅从 python.org 下载，pip bootstrap 仅从 bootstrap.pypa.io 下载，openpyxl 固定为 `3.1.5`、et-xmlfile 固定为 `2.0.0`，只通过 `python -m pip --isolated install --index-url https://pypi.org/simple --no-input --disable-pip-version-check` 从官方 PyPI 安装，不读取本机 pip 配置或环境镜像。无网、非 Windows 10 x64 或权限受限时，会在诊断报告中给出清晰中文说明并停止。
- 不修改 Excel、PSD、素材原文件。
- Photoshop 是唯一 PSD 替换与 JPG 渲染引擎。
- JPG 导出质量 10，尺寸跟随 PSD 画布。
- 同名 JPG 不覆盖，会自动追加 `_1`、`_2`。
