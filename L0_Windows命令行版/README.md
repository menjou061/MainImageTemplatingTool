# 电商主图套版工具 1.4.0（Windows）

## 开始使用

1. 把安装包完整解压到本地文件夹，不要在压缩包里直接运行。
2. 手动启动 Adobe Photoshop，完成登录并等待 Photoshop 首页显示。
3. 保持 Photoshop 开启，再双击 `开始套版.cmd`。
4. 先选择品类和渠道，再选择对应的商品表格、运营 Sheet 和 PSD 模板。
5. 选择全部商品或勾选部分商品，点击“开始生成”。工具只生成当前 Sheet 对应的一个规格，不会同时生成另一规格。如果 Photoshop 没有启动，工具会留在当前页面提醒，不会创建失败任务。

首次使用和团队标准文件见 [飞书说明中心](https://pcnfsebpg8ae.feishu.cn/wiki/GNKXw8E1SipzcnkrrF9c0vOnnze)。

## 选择标准文件

标准 Excel 与 PSD 不再随工具包发送。请从飞书说明中心按“品类 → 渠道”下载一对一的标准 Excel 和 PSD，再在工具中成对选择；不要只按画布尺寸或文件名片段挑模板。

1. 复制标准 Excel 到本次项目文件夹后再填写，不直接修改飞书下载的基准文件。
2. 运营只填写字段值和 Windows 可访问的素材路径；不要改字段名称、Sheet 名和规格字段。
3. 设计只在对应渠道 PSD 上增加图层或调整视觉样式；不要删除既有 `@`、`!`、`#` 图层命名。
4. 新增字段时，表格字段名必须与 PSD 去掉前缀后的图层名完全一致。

当前 Windows 电脑不能访问共享目录时，必须把图片单元格改成自己能打开的本地路径或共享路径。隐藏工作表和 `WpsReserved_CellImgList` 不需要修改，工具会自动忽略。

同一张表可以放多个可见运营 Sheet。天猫官旗的 `现货-750` 和 `现货-800` 分别对应不同 PSD；每次运行只选择一个 Sheet 和一个 PSD。Sheet 未在渠道配置中登记时会记录 `E_PROFILE_SHEET_MISMATCH` 并阻断本次任务，不会猜测模板。

工具启动时先选择“品类”和“渠道”，随后只展示并校验该组合的 Excel、Sheet 和 PSD。纸品京东、纸品天猫、纸品恒安，以及卫品天猫，即使尺寸相同也不能互换；选错组合会在 Photoshop 出图前阻断。

卫品+天猫官旗使用飞书中的 `卫品_天猫官旗_v1.3_动态字段标准.xlsx`。长图使用 `出图数据`，750×750 方图使用 `出图数据_750x750`；方图没有赠品字段，必须选择无赠品方图 PSD。

## 最简单的保存规则

没有手动更改时，成品默认保存在桌面的 `电商主图套版成品` 文件夹。每次任务都会新建独立目录，不覆盖以前的结果：

```text
套版成品_2026-07-27_143000_工作表名/
├─ JPG成品/      可直接交付的图片
├─ PSD源文件/    可继续编辑的 PSD
└─ 任务记录/     异常清单、生成结果和任务日志
```

任务中的异常商品会自动跳过，原因写入 `任务记录/异常记录.csv`；程序运行失败也只写任务记录，不反复弹出长错误信息。

## 表格与素材规则

- 商品信息表格使用 `.xlsx`。
- `商品图` 必须填写 Windows 能直接访问的完整路径，例如 `D:\商品素材\TKDT3180-3.png` 或 `\\服务器\共享目录\TKDT3180-3.png`。
- 可选图片未使用时填写 `无`、`无.png` 或留空。
- 素材可以放在任意本地或已授权共享目录，工具不会移动、修改或扫描素材原文件。
- `价格1` 和 `价格2` 都需要填写；`价格2` 按原文展示。

## PSD 图层规则

- `@字段名`：文本层，例如 `@卖点`、`@价格1`。
- `!字段名`：智能对象图片层，例如 `!商品图`。
- `#字段名`：可选显示组。组内任意同名 `@` 或 `!` 图层在表格中有值时显示；全部为空时隐藏。

同名字段是唯一匹配依据：Excel `价格3` 对应 PSD `@价格3`，Excel `赠品浮窗` 对应 PSD `!赠品浮窗`。新增字段不需要改脚本。图片素材会等比缩放到原智能对象展示框；文字保留 PSD 图层原有字号和样式。详细示例见飞书说明中心。

工具检查到普通 PSD 尚未完成套版命名时，会询问是否生成一个 `_套版模板.psd` 副本。原始 PSD 不会被修改。

卫品三栏会员支持从旧的多 SKU 固定组合字段 PSD 自动生成单版式动态副本：工具只保留一个基础组合，把 `产品` 组转换为 `!商品图` 智能对象，之后每一行商品组合都按表格里的商品图路径替换，SKU 数量不需要写进 PSD。

### 卫品 + 天猫官旗标准模板

当前交付 `750×1000` 三栏赠品和 `750×750` 无赠品两种规格。长图使用 `出图数据`，方图使用 `出图数据_750x750`；选择其他 Sheet、跨渠道 PSD 或把方图与赠品 PSD 混用，都会直接阻止任务。选择的 Sheet、品类/渠道和 PSD 身份必须匹配；任何一项不唯一、错渠道或错规格都会在 Photoshop 启动前阻断。

卫品模板必须按下面的结果命名，设计师可以移动、改颜色和重排版，但不要删除这些绑定：

- 大字号数字：`@价格活动价`、`@价格优惠券`、`@价格立减`、`@到手`、`@片数数量`。
- 数字下方小字：`@价格活动价副标`、`@价格优惠券副标`、`@到手标签`、`@片数套`。
- 商品和赠品：`!商品图`、`!赠品图1`、`!赠品图2`、`!赠品图3`，每个字段只能对应一个智能对象；画布要紧贴素材并放在对应裁切框内。一个赠品槽位如果保留多个原素材对象，工具会阻止跑批，避免出现叠图。
- 赠品文案：`@赠品文案1` 至 `@赠品文案3`；顶层赠品组使用 `#赠品顶部`，下方赠品区域使用 `#赠品区域`。

如果赠品智能对象没有裁切框、画布留有大面积透明边，工具会在任务记录中标记模板需标准化，不应直接交付成品。

一个 PSD 可以保留多套已经标准化的版式，但表格中的“模板版式”必须与当前渠道配置完全一致。模板预检只检查本次任务选中的版式；如果多版式 PSD 仍是设计原稿、字段没有标准化，工具会记录 `E_TEMPLATE_PREP_REQUIRED` 并停止，不会在设计师跑批时长时间自动改造原稿。请业务方先确认一份标准副本，建议与原 PSD 放在同一文件夹并命名为“原文件名_套版模板.psd”；工具会自动优先体检并使用这份副本。选中的版式缺失、重复或字段绑定不完整也会阻断任务并写入任务记录；原始 PSD 不会被修改。

每个批准 PSD 必须在同目录提供 `原文件.psd.template.json`。该身份文件包含渠道 profile、规格、`template_id` 和 PSD 的 SHA-256。缺失、规格不符或 PSD 内容被替换时会记录 `E_TEMPLATE_IDENTITY_MISSING` 或 `E_TEMPLATE_IDENTITY_MISMATCH`，不会依据相同画布尺寸或相似图层继续生成。

## 使用要求

- Windows 10 x64 或更高版本。
- Windows 版 Adobe Photoshop，可正常启动并已完成授权；运行工具前需要先打开 Photoshop 并进入首页。
- 工具包必须完整解压；不要单独复制 `开始套版.cmd`。
- 共享路径需先在 Windows 资源管理器中确认可以打开。
- 工具内置 Python 3.11.9、openpyxl 3.1.5 和 et-xmlfile 2.0.0，正常首次运行不需要联网，也不需要安装 Python。

## Photoshop 兼容与报错

v1.3 延续 v1.0 在 Adobe Photoshop 2026（27.2）的验证基线。其他 Windows 正式版不会只因版本号不同而被拦截：设置页先检查 Photoshop 的进程、响应状态、主窗口和安装版本，正式启动阶段再检查 COM 自动化与 JSX 脚本接口。

- 没有启动 Photoshop：停留在设置页，提醒先启动并登录。
- Photoshop 正在启动，或有登录、授权、更新等弹窗：提醒处理后进入首页再试。
- Photoshop 安装注册损坏、自动化接口不可用或版本不兼容：提醒重启或修复 Photoshop，技术原因写入工具任务记录。
- 生成中出现模板、脚本或 Photoshop 内部错误：不反复弹出长报错，详情写入本次成品的 `任务记录`。

Photoshop 单次 JSX 调用默认最多运行 900 秒（15 分钟）。超时会记录
`E_PHOTOSHOP_TIMEOUT` 并判定任务失败，不会显示为成功。需要调整时，可在启动前设置
`MAINIMAGE_PHOTOSHOP_TIMEOUT_SECONDS`（30-7200 秒），或在
`%LOCALAPPDATA%\电商主图套版工具\settings.json` 写入 `photoshopTimeoutSeconds`。
任务完成前还会检查 `生成结果.csv`、JPG 文件头、PSD 的 `8BPS` 文件头和可编辑图层；
缺失、截断或无图层的产物会记录 `E_OUTPUT_INCOMPLETE` 并判定失败。

## 故障记录

任务相关文件在本次成品目录的 `任务记录` 中。工具级任务历史与启动诊断保存在：

```text
%LOCALAPPDATA%\电商主图套版工具\任务记录
```

需要开发同事排查时，提供本次成品目录中的 `任务记录` 文件夹；如果没有生成任务目录，再提供上面的工具级任务记录目录。

如果双击 `开始套版.cmd` 后主界面完全没有出现，再提供最早期启动日志：

```text
%LOCALAPPDATA%\MainImageTemplatingTool\startup
```

正常启动时，入口 CMD 窗口会自动隐藏，只保留工具自己的设置、进度和完成窗口；启动日志和任务记录仍会保留。开发排查需要查看 CMD 时，可以在启动前设置环境变量 `L0_SHOW_CONSOLE=1`。
