# 电商主图套版工具 1.0（Windows）

## 开始使用

1. 把安装包完整解压到本地文件夹，不要在压缩包里直接运行。
2. 手动启动 Adobe Photoshop，完成登录并等待 Photoshop 首页显示。
3. 保持 Photoshop 开启，再双击 `开始套版.cmd`。
4. 选择商品信息表格和 PSD 模板。
5. 确认工作表与商品范围，点击“开始生成”。如果 Photoshop 没有启动，工具会留在当前页面提醒，不会创建失败任务。

首次使用和团队交付说明见同目录的 `新手教程.url`。

## 直接使用案例表

安装包内置 `示例文件/表格案例_618正式主图.xlsx`，它就是当前工具使用的横向商品表标准案例。第一次使用时：

1. 把案例表复制到本次项目文件夹并另存一个新名字，不要直接修改安装包里的原文件。
2. 第一行从 B 列开始填写商品文件名，第一列保留字段名称；每个商品占一列。
3. 替换商品数据和图片完整路径，不需要的商品列可以删除。
4. 在工具里选择这个 Excel，再选择要处理的可见工作表。

案例表保留了原项目的共享素材路径。当前电脑不能访问该共享目录时，必须把图片单元格改成自己能打开的本地路径或共享路径。隐藏工作表和 `WpsReserved_CellImgList` 不需要修改，工具会自动忽略。

## 最简单的保存规则

没有手动更改时，成品默认保存在桌面的 `电商主图套版成品` 文件夹。每次任务都会新建独立目录，不覆盖以前的结果：

```text
套版成品_2026-07-27_143000_工作表名/
├─ JPG成品/      可直接交付的图片
├─ PSD源文件/    可继续编辑的 PSD
└─ 任务记录/     异常清单、生成结果和任务日志
```

任务中的异常商品会自动跳过，原因写入 `任务记录/异常记录.csv`；程序运行失败也只写任务记录，不反复弹出长错误信息。

## 表格与素材规则

- 商品信息表格使用 `.xlsx`。
- `商品图` 必须填写 Windows 能直接访问的完整路径，例如 `D:\商品素材\TKDT3180-3.png` 或 `\\服务器\共享目录\TKDT3180-3.png`。
- 可选图片未使用时填写 `无`、`无.png` 或留空。
- 素材可以放在任意本地或已授权共享目录，工具不会移动、修改或扫描素材原文件。
- `价格1` 和 `价格2` 都需要填写；`价格2` 按原文展示。

## PSD 图层规则

- `@字段名`：文本层，例如 `@卖点`、`@价格1`。
- `!字段名`：智能对象图片层，例如 `!商品图`。
- `#字段名`：可选开关组或图层。

工具检查到普通 PSD 尚未完成套版命名时，会询问是否生成一个 `_套版模板.psd` 副本。原始 PSD 不会被修改。

## 使用要求

- Windows 10 x64 或更高版本。
- Windows 版 Adobe Photoshop，可正常启动并已完成授权；运行工具前需要先打开 Photoshop 并进入首页。
- 工具包必须完整解压；不要单独复制 `开始套版.cmd`。
- 共享路径需先在 Windows 资源管理器中确认可以打开。
- 工具内置 Python 3.11.9、openpyxl 3.1.5 和 et-xmlfile 2.0.0，正常首次运行不需要联网，也不需要安装 Python。

## Photoshop 兼容与报错

v1.0 已在 Adobe Photoshop 2026（27.2）完成全流程验证。其他 Windows 正式版不会只因版本号不同而被拦截：设置页先检查 Photoshop 的进程、响应状态、主窗口和安装版本，正式启动阶段再检查 COM 自动化与 JSX 脚本接口。

- 没有启动 Photoshop：停留在设置页，提醒先启动并登录。
- Photoshop 正在启动，或有登录、授权、更新等弹窗：提醒处理后进入首页再试。
- Photoshop 安装注册损坏、自动化接口不可用或版本不兼容：提醒重启或修复 Photoshop，技术原因写入工具任务记录。
- 生成中出现模板、脚本或 Photoshop 内部错误：不反复弹出长报错，详情写入本次成品的 `任务记录`。

## 故障记录

任务相关文件在本次成品目录的 `任务记录` 中。工具级任务历史与启动诊断保存在：

```text
%LOCALAPPDATA%\电商主图套版工具\任务记录
```

需要开发同事排查时，提供本次成品目录中的 `任务记录` 文件夹；如果没有生成任务目录，再提供上面的工具级任务记录目录。
