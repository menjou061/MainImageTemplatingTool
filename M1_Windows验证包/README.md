# M1 Windows Photoshop COM 一键验证包

这个包用于验证当前 Windows 电脑是否可以通过 COM 启动 Photoshop，并执行一个最小 JSX 脚本。它只做连通性验证，不启动批量套版，不打开或修改任何 PSD。

## 使用方式

请先把整个验证包文件夹复制到本机本地目录后再运行，不要在压缩包预览窗口里直接双击运行。

1. 双击 `M1_一键验证.bat`。
2. 等待 Photoshop 自动打开或切到前台。
3. 验证结束后，会自动打开 `输出` 文件夹。
4. 把 `输出` 文件夹里的 `M1验证报告.txt` 和 `M1验证报告.csv` 交给开发同事。

如果双击 `M1_一键验证.bat` 后窗口闪一下就消失，请双击 `M1_调试启动.cmd`。诊断窗口会保持打开，并在 `输出/M1启动日志.txt` 记录启动过程；请把整个 `输出` 文件夹发回开发同事。

## 会产生哪些文件

- `输出/M1验证报告.txt`：给人看的中文报告，包含通过/未通过、环境信息、失败摘要和建议动作。
- `输出/M1验证报告.csv`：给开发排查用的结构化结果。
- `输出/M1启动日志.txt`：使用 `M1_调试启动.cmd` 时产生的启动诊断日志。
- `输出/M1_Photoshop_COM_marker_*.txt`：JSX 成功执行时写出的本次 GUID 标记文件。

## 报告包含什么

报告会记录状态、时间、Windows 版本、PowerShell 版本、Photoshop 路径、Photoshop 版本、COM 启动结果、JSX 执行结果、标记回传结果、错误摘要和建议动作。

## 失败时怎么办

如果状态是“未通过”，不要反复重试。请确认 Photoshop 能手动正常打开，然后把 `输出` 文件夹完整发给开发同事。开发会根据报告判断是 Photoshop 未安装、COM 注册异常、JSX 执行异常，还是输出目录写入/中文路径兼容问题。

## 已知限制

- 只支持 Windows 环境；Mac 不能运行 Windows COM 验证。
- 需要本机已安装 Windows 版 Adobe Photoshop。
- 不需要管理员权限，不会长期修改 PowerShell 执行策略。
- 不依赖 Python、Node 或网络。
