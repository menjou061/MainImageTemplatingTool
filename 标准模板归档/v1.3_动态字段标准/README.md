# v1.3 动态字段标准模板

本目录是四个已启用渠道的 v1.3 标准交付物，包含运营 Excel、设计 PSD 和字段绑定清单。

面向运营和设计的发布说明分别见：

- `运营表格字段规范_v1.4.md`
- `设计PSD图层规范_v1.4.md`
- `飞书渠道附件清单_v1.4.md`

## 唯一匹配规则

- Excel 字段 `价格3` 对应 PSD 文本层 `@价格3`。
- Excel 字段 `商品图` 对应 PSD 智能对象 `!商品图`。
- Excel 字段 `赠品区域` 填 `是/否` 时，对应 PSD 显示组 `#赠品区域`。
- 新增文本或图片字段时，表格字段名与 PSD 去掉前缀后的名称必须完全一致；无需修改脚本。
- `产品`、`堆图`、`产品图路径`、`图片目录路径`、`变量01` 等旧名称仅用于兼容历史文件，新模板不要继续使用。

## 文件目录

- `Excel/`：京东自营、天猫官旗、恒安生活馆、卫品天猫的 v1.3 标准工作簿。
- `PSD/`：五份纸品规格模板和两份卫品天猫模板，源文件均保留在上级归档目录。
- `PSD_动态字段令牌清单.csv`：模板画布、商品图片令牌和可选字段说明。

## 交付前检查

设计师增加字段时，应在版面上先确定位置，再复制同风格图层并命名为 `@字段名` 或 `!字段名`。`@价格3` 没有固定位置，未设计位置时不要凭空复制图层。工具会报告表格存在但 PSD 缺少绑定的字段，不会静默丢弃。

每次任务仍只选择一个渠道、一个 Sheet 和一个规格。完成生产发布前，必须在 Windows Photoshop 实机跑一条商品，确认 JPG、可编辑 PSD、任务记录和异常记录均正常。
